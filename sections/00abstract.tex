\begin{abstract}
	Small bioactivity data sets make it easy to overstate the benefit of complex models, through data leakage and
	through model selection that is rarely evaluated on unseen data. We re-examined both for inhibitors of
	\textit{Toxoplasma gondii} dihydrofolate reductase (TgDHFR, $N = \NCompounds$ curated compounds). Removing the
	information leaks of the original study's code one at a time lowered its $R^2$ from
	\KarLadderRungZeroRTwoMean\ to \KarLadderRungFourRTwoMean, the level of a model with no feature selection; the
	largest contribution was a feature importance computed on the test molecules. The same leak on a classical
	learner reproduced the reported gain (\ExpBleakyRTwoMean\ against \ExpBRTwoMean\ when kept clean).

	Leakage-free, four classical representations and seven neural models were scored on the same
	\TotalOuterFolds\ outer folds of a repeated nested cross-validation. Morgan-fingerprint ensembles reached $R^2 =
	\MorganRTwoMean \pm \MorganRTwoStd$, and ten 3D shape descriptors added to the best descriptor set changed
	nothing ($\Delta R^2 = \NBdiffRTwoTwoDFpVsTwoDThreeDFp$). A Directed Message Passing Neural Network reached
	\ChemPropDMPNNFoldRTwoMean\ by default and \GnnTunedRTwoMean\ after a nested search, below the fingerprint
	ensembles by a margin that cleared multiple-comparison correction only narrowly (smallest adjusted $p =
	\GnnTunedVsMinPRTwo$). Only a network initialized from a pretrained foundation model matched them
	(\ChemeleonRTwoMean, equivalent in both metrics), at eight times the cost; none exceeded them. Scaffold-grouped
	splits cost every model between \ScaffoldDropMin\ and \ScaffoldDropMax\ units of $R^2$.

	On an FDA-approved library the deployed model placed only \ScreenNDomain\ of \ScreenNStructural\ scored compounds
	inside its applicability domain (median similarity \ScreenADFdaMedian\ against \ScreenADTrainMedian\ internally), so its \AdmetNConsensus\ consensus hits, \AdmetNConsensusSurvivors\ of them passing ADMET filters,
	are hypotheses rather than leads. For this target a fixed-fingerprint ensemble was sufficient; we make no claim
	beyond it.
\end{abstract}

\textbf{Keywords:} 
Quantitative Structure-Activity Relationship, Low-Data Regimes, Nested Cross-Validation, Data Leakage, Graph Neural Networks, Molecular Docking
